#  Telegram-бот «Дневник настроения»

Асинхронный Telegram-бот для отслеживания ежедневного настроения с текстовой аналитикой и графиками.

##  Возможности
- **Ежедневные записи:** оценка от 1 до 10 и короткая заметка о прошедшем дне.
- **Редактирование:** возможность изменить запись за текущий день (благодаря `UPSERT` в SQLite).
- **Статистика:** график настроения в виде текстовых баров (за неделю и месяц).
- **Стрики (Streaks):** подсчет количества дней подряд, когда пользователь делал записи.
- **Экспорт данных:** выгрузка всей истории в CSV-файл (поддерживается кодировка для Excel).
- **Локальный обход блокировок:** встроена поддержка локального SOCKS5-прокси для работы в условиях ограниченного доступа к API Telegram.

##  Стек технологий
- **Python 3.15+**
- **aiogram 3.x** (асинхронный фреймворк для Telegram)
- **SQLite + aiosqlite** (асинхронная работа с базой данных)
- **python-dotenv** (безопасное хранение токенов)

##  Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_никнейм/mood-diary-bot.git
   cd mood-diary-bot

2. Создайте виртуальное окружение и установите зависимости:
    python -m venv .venv
    # Windows:
    .venv\Scripts\activate
    # Linux/macOS:
    source .venv/bin/activate
    pip install -r requirements.txt

3. Настройте переменные окружения:
Создайте файл .env в корне проекта и добавьте туда токен от @BotFather:
    BOT_TOKEN=ваш_токен_здесь

4. Запуск бота:
    python bot.py
